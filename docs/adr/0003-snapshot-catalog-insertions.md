# Save independent copies of catalog and personal artwork

Accepted for the planned presentation feature; not yet implemented. Catalog assets, template dependencies and personal stickers are copied into student presentations with immutable bytes and provenance, rather than remaining live links to editable catalog or sticker content. This increases local storage and backup size but preserves saved presentations after catalog updates, archiving, source edits or outages; SVG artwork initially behaves as one image rather than editable vector parts.
