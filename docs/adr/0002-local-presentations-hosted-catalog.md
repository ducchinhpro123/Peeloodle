# Keep student presentations local while hosting the curated catalog

Accepted for the planned first release; not yet implemented. Extend the existing Supabase backend for administrator-managed assets and templates, while students save presentations locally and transfer work through exports or portable backups. This delivers catalog publishing without making cloud student storage, account migration and collaboration prerequisites; automatic cross-device presentation access is deferred.

See [architecture](../slides-architecture.md) and [implementation plan](../slides-implementation-plan.md).
