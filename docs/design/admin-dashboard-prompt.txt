Use case: ui-mockup
Asset type: high fidelity desktop admin dashboard UI concept for StickerLab, to embed in an implementation planning document.
Primary request: Design a polished, practical catalog administration dashboard for one administrator managing free stickers, icons and editable university presentation templates. Wide landscape straight-on application screenshot, no device frame.
Style: original StickerLab identity, near-white #fafbf8 surfaces, dark navy #08152f typography, mint #ddf7ed sidebar and emerald #00875e primary buttons, rounded cards, delicate borders, restrained pastel artwork. Calm work interface, lively original outlined sticker thumbnails. Clean highly readable sans serif.
Layout: left sidebar branded StickerLab / Admin with Assets selected, Collections, Presentation templates, Uploads; bottom Back to app. Top heading Asset library and small clear label Concept • Sample content. Top right primary Upload assets and secondary New collection. Search field and collection/type filters. Status tabs All, Draft, Published, Archived.
Main area: six beautiful asset cards in a three-column grid, playful original star, rocket, notebook, leaf, speech bubble, graduation cap; selection checkboxes, concise names, PNG/WebP/SVG badges and Draft/Published labels.
Right side panel: Selected asset with preview of rocket, editable name Little rocket, collection Campus essentials, tags space and science, provenance field Source / permission, status Draft. Bottom Save draft and Publish buttons. Publish checks visible as Ready for review.
Bottom main area: compact bulk upload queue named Upload batch, with three rows: notebook.png Ready; arrow.svg Needs review; star.webp Upload failed with Retry. Header text PNG, WebP, SVG. Upload errors are legible, not decorative.
Include a compact Presentation templates preview strip beneath the grid with three 16:9 miniature deck covers: Class presentation, Research defense, Club pitch, plus Manage templates link. No charts, revenue, fake usage statistics, subscription upsells, or collaboration controls. Generous usable spacing. Screenshot is a design concept, not a functional app.
