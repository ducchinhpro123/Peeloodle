# Background-removal fixtures

Deterministic inputs for `e2e/cutout.spec.ts`. Regenerate with:

```sh
node e2e/fixtures/cutout/build-fixtures.mjs
```

| File               | Content                                                              |
| ------------------ | -------------------------------------------------------------------- |
| `peace-selfie.png` | Person subject composited at 1024×1024 onto the busy background.     |
| `sunny-corgi.png`  | Pet subject, same background.                                        |
| `boba-tea.png`     | Object subject, same background.                                     |
| `<name>.truth.png` | The subject's own alpha as grayscale: ground truth for the IoU gate. |
| `no-subject.png`   | The background alone.                                                |

## Provenance

- **Subjects:** `static/art/template-photos/{peace-selfie,sunny-corgi,boba-tea}.webp`, the
  1024×1024 template photo derivatives with real alpha documented in
  `docs/assets-provenance.md` (template photos section). The subject alpha (including the
  die-cut white outline and baked doodles) is used unchanged as the ground truth.
- **Background:** generated by `build-fixtures.mjs` with `sharp` raw buffers and a
  mulberry32 PRNG, **seed 42**: 64×64 colour noise upscaled (cubic) and blurred (σ 6)
  into soft blobs, then 40 random filled circles/rectangles. The blur keeps each PNG
  well under 1.5 MB without shrinking below 1024².
- The generator is byte-for-byte deterministic for a given `sharp`/libvips version.
