# Background-removal fixtures

Deterministic inputs for `e2e/cutout.spec.ts`. Regenerate with:

```sh
node e2e/fixtures/cutout/build-fixtures.mjs
```

| File                  | Role                          | Content                                                                                        |
| --------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------- |
| `<name>.png`          | **Gating** (IoU ≥ 0.90)       | Subject composited at 1024×1024 onto the realistic background.                                 |
| `<name>.clutter.png`  | Benchmark, non-gating         | Same subject on the realistic background plus 40 flat circles/rectangles.                      |
| `<name>.truth.png`    | Ground truth                  | The subject's own alpha as grayscale, shared by both variants.                                 |
| `no-subject.png`      | "No clear subject" case       | The realistic background alone.                                                                |
| `rotated-6.jpg`       | EXIF orientation (IoU ≥ 0.90) | `sunny-corgi.png` stored 90° CCW in pixels, tagged EXIF orientation 6, so it displays upright. |
| `rotated-6.truth.png` | Ground truth                  | The subject alpha in display orientation (equal to `sunny-corgi.truth.png`).                   |

`<name>` is `peace-selfie` (person), `sunny-corgi` (pet) and `boba-tea` (object).

## Why the clutter set does not gate

The realistic background (blurred colour noise, like an out-of-focus scene) is what the
quality gate measures. The clutter variant adds 40 large flat-colour shapes that touch and
overlap the die-cut sticker edges. Salient-object models such as ISNet reasonably treat those
shapes as foreground objects, or merge the sticker's white border into them. On that set the
shipped model scores well below 0.90 (e.g. ~0.63 on the pet). fp32 and int8 builds score the
same, so quantisation is not the cause. The clutter results are recorded alongside the gating
ones as a robustness benchmark. They never fail the test.

## Provenance

- **Subjects:** `static/art/template-photos/{peace-selfie,sunny-corgi,boba-tea}.webp`. These are
  the 1024×1024 template photo derivatives with real alpha, documented in
  `docs/assets-provenance.md` (template photos section). The subject alpha, including the die-cut
  white outline and baked doodles, is used unchanged as the ground truth.
- **Backgrounds:** generated by `build-fixtures.mjs` from `sharp` raw buffers and a mulberry32
  PRNG with **seed 42**:
  - Realistic: 64×64 colour noise, upscaled (cubic) and blurred (σ 6) into soft blobs.
  - Clutter: the same image plus 40 random filled circles/rectangles.

  The blur keeps each PNG well under 1.5 MB without shrinking below 1024².

- The generator is byte-for-byte deterministic for a given `sharp`/libvips version.
