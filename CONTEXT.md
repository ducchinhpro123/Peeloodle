# StickerLab

StickerLab creates editable photo stickers and organizes them into packs.

## Language

**Draft**:
The current editable state of an open sticker project, including changes that may not yet be saved. A draft can belong to a new project or a previously saved project.

**Draft saving**:
Preserving a draft's document and its referenced images and masks locally so the saved composition can be reopened.
